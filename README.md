A small Python program that writes a one-line honest appliance error message, under 200 characters, to /output/entry.txt. The line never changes — every run produces the same 154-character line, in which an espresso machine reports that its descale is 214 days overdue, it has brewed 1,842 cups through solid limescale, the espresso now crunches, and the limescale has a name: Gerald.

## Run it

Run the script from the repo root — it validates the line, then writes it to /output/entry.txt:

```sh
python3 main.py
```
